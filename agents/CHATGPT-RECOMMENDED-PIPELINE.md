# CHATGPT-RECOMMENDED ARTICLE PIPELINE (Sturm method, adapted) - MANDATORY
For every article intended to surface in ChatGPT/AI answers. Supersedes ad-hoc drafting.
1. QUERY MINING: pick the buyer query; if a real ChatGPT session is available, capture its
   internal search queries (network panel, 'queries' in response) - else derive 3-5
   canonical sub-queries from DataForSEO 'People also ask' + related.
2. SERP HEADINGS: DataForSEO organic top-10 for the exact query; extract H2/H3 of top 3.
3. OUTLINE: 10x-method gap analysis on those headings; improved outline (information gain).
4. DRAFT: TLDR first (2-3 sentences, answers the query immediately), clear sections,
   short paragraphs, house voice (VOICE-DNA), facts from facts.md gates only.
5. METADATA: title, confident meta description, slug.
6. HUMANIZE: real specifics (inventory, prices, local facts), no em-dashes, no buzzwords,
   no press-release tone; pass social-caption-voice-fix style read.
7. PUBLISH PREP: DealerOn-format HTML + internal links FROM 2-3 already-ranking pages
   (see agents/internal-links.md) + GSC request-indexing via API after publish.
Non-negotiables: no invented facts; every number sourced; no AI-pattern phrasing.
