# 7. DealerOn content brief

## Purpose
Turn a reviewed opportunity into an implementable draft without conflicting with the staged used-inventory package.

## Inputs
Reviewed job 5 candidate; jobs 1, 6, 8 and 9 where available; current factual inventory/service sources; current page HTML/canonical; staged package `MOTORINN-SEO-STAGING-4a2aaec73b56bb4638eef49a5d6a9b4d`.

## Staged package dependency
The package ID is supplied by Spencer; its contents were not found in this SEO repository during this build. Obtain its exact preview/export and manifest from the existing DealerOn staging owner before declaring the brief implementation-ready. Record staging URL, target host/path, title/H1/body/canonical, schema, links, status and retrieval date. Do not recreate, supersede or publish it based on its ID alone. Missing package = `BLOCKED-STAGING-READ` for affected used-inventory changes; an outline may still be drafted.

## Exact steps
1. Confirm a recorded review decision and exact intended host/page. If unreviewed, label the brief `research-draft`, not approved.
2. Read the staged package for used-inventory work; compare its proposed behavior to the current page. Document retain/change decisions and overlap with `/searchused.aspx`, `/used-trucks`, `/used-suvs`.
3. Write a direct buyer answer, verified differentiators and inventory/service route. Use Carroll and relevant nearby towns naturally. Never assert stock, pricing, towing capacity, financing approval, hours or drive time without a current source.
4. Supply title, meta description, H1, outline, key answers, content blocks, internal links, CTA and schema plan. Avoid keyword stuffing and unsupported best/lowest-price claims.
5. For vehicle offers, require exact vehicle/source date and approved disclosure copy. Keep finance application details on the secure existing provider. Use existing DealerOn schema where possible; avoid duplicate/conflicting entities.
6. State acceptance checks: responsive preview; correct canonical/indexability; HTTP status; working inventory/scheduler links; no duplicate H1/schema; current facts; clear ownership; staging comparison. Set publication status to NOT AUTHORIZED.
7. Write the brief and attach source references. Do not send it to DealerOn or move it to published.
