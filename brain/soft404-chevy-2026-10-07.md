## Pattern diagnosis

The window-sticker component on the DealerOn platform writes a fixed file named
`windowstickernotfound.pdf` into `/resources/components/windowstickers/` and serves it
with HTTP 200 at a VIN-specific URL whenever a real window sticker is missing for that
vehicle. Because it returns 200 and is a valid PDF, Google indexes it as a "Soft 404":
valid HTTP response, useless content. It is not in the sitemap (verified: 164 locs,
0 contain "windowsticker"), so Google is discovering these URLs through internal links
or direct crawling, and GSC still flags them.

## Recommended fix

Ask DealerOn to stop serving the placeholder PDF at 200. Instead:
- return `HTTP 404` (or `410`) for any `windowsticker*.pdf` whose real sticker is
  unavailable, and
- remove or 410 the placeholder file `windowstickernotfound.pdf` entirely.

This converts the soft 404 into a true 404/410, which Google will process as "page not
found" instead of "soft 404", and eliminates the placeholder content from the index.
